PUBLISH WITH GITHUB PAGES
1. Create a GitHub repository named summer-house-villa-51.
2. Upload the contents of this folder to the repository root (index.html,
   images/, favicon.svg, og-image.jpg, robots.txt, sitemap.xml, 404.html,
   and .nojekyll).
3. In the repository, open Settings > Pages.
4. Choose Deploy from a branch, select main and /(root), then Save.
5. Wait for the published URL to appear.
6. Once you know the final URL, update the canonical URL, Open Graph URL/image,
   sitemap.xml and robots.txt if needed.
